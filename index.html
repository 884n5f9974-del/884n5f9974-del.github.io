Codex VPS Backup

This is a personal backup utility for its owner. It uses rclone and restic to store encrypted backups of the owner's Codex files in the owner's Google Drive account, and to retrieve those backups for recovery.

It requests the Google Drive drive.file permission, which limits access to files created by this app. The backup files are encrypted before they are uploaded.

This page is informational. It has no sign-in form, tracking, or analytics.
